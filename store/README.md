## Setup

### 1. Get your Admin API token

In your Shopify admin:

1. **Settings** → **Apps and sales channels**
2. **Develop apps** → **Allow custom app development** (one-off confirmation)
3. **Create an app** → name it `Store Setup`
4. **Configure Admin API scopes** — tick exactly these:

   ```
   write_products      read_products
   write_publications  read_publications
   write_content       read_content
   write_inventory     read_inventory
                       read_locations
   ```

5. **Save** → **Install app**
6. **Reveal token once** and copy it. It starts with `shpat_`.

> **On the token:** it is a password to your store. It is shown once. Keep it out of git (`.env` is already gitignored), and **delete the custom app in Shopify once setup is done** — it takes five seconds and closes the door behind you. Nothing here needs ongoing access.

### 2. Configure

```bash
cd store/shopify
cp .env.example .env
# edit .env with your domain and token
```

### 3. Check compliance

```bash
npm run check
```

Scans every product description and page for therapeutic-claim language. Exits non-zero if anything would reclassify a product as a regulated therapeutic good. **Run this after any copy edit.**

### 4. Preview

```bash
set -a && source .env && set +a
npm run preview
```

Connects, verifies your credentials and currency, and prints exactly what it would create. Changes nothing.

### 5. Apply

```bash
npm run setup          # products go live (ACTIVE)
npm run setup:draft    # or create as DRAFT to review first
```

Safe to re-run — anything that already exists by handle is skipped.

## What the script creates

- **5 products** with description, price, compare-at price, SKU, cost-per-item, weight, tags, and stock level
- **3 collections**, with products assigned
- **5 content pages**
- Everything published to the Online Store sales channel

## What it deliberately does not do

These need your decisions or a human in the admin UI:

- [ ] **Payments** — Settings → Payments. Shopify Payments supports NZD; enable it and add your bank account
- [ ] **Navigation menu** — Content → Menus. Suggested: Shop / The Ritual / Guide / About / FAQ
- [ ] **Shipping rates** — Settings → Shipping. Match the rates in `content/pages.json` (NZ $6, rural $10, free over $100; AU $14, free over $150)
- [ ] **Digital delivery** — install a digital-downloads app for the Protocol PDF
- [ ] **Legal policies** — Settings → Policies. Privacy and Terms are generated by Shopify; `content/pages.json` covers Shipping and Returns
- [ ] **Theme** — see `theme/` and the brand palette
- [ ] **Domain** — verify `slowwave.co.nz` is available before committing to the name

## Before you spend money

1. **Clear the name.** Check domain availability and search the IPONZ + IP Australia trade mark registers. Do not print packaging first.
2. **Order samples** before the 100-unit buy. You have not seen this stock.
3. **Launch tier 1 only.** The digital product carries no inventory risk. Find out whether the positioning converts *before* spending the $300 on stock. This ordering is the single biggest protection in the whole plan.
4. **Replace every `[BRACKETED]` placeholder** in `content/pages.json`. The Fair Trading Act requires a real, contactable trader identity.

## Troubleshooting

| Error | Fix |
|---|---|
| `Auth failed (HTTP 401/403)` | Token wrong, or a scope is missing. Re-check the scope list above |
| `Store not found` | `SHOPIFY_STORE_DOMAIN` wrong — use the `.myshopify.com` domain, not a custom one |
| `No "Online Store" sales channel` | Online Store channel isn't installed on the store |
| `stock not set` warning | Missing `write_inventory` / `read_locations`. Harmless — set quantities in admin |
| Throttling | Handled automatically with backoff |
